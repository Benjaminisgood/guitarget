# 原生曲谱文档与编辑器

`GuitarScoreDocument` 通过 SwiftUI `DocumentGroup` 接入 macOS 原生新建、打开、保存、另存为、未保存状态和关闭流程。文件使用 `com.guitarget.score` / `.guitarget` 类型，严格调用 `GuitarCore.ScoreIO` 读取和写入 JSON。版本、节奏、声部、弦位和技巧验证失败会抛出原生打开错误，读取过程不写原文件。原生文件菜单中的“复制”或按 Option 后的“存储为”可以另存副本。

`ScoreEditorState` 持有选择状态，曲谱由 `FileDocument` 的 Binding 管理。每次渲染刷新 Binding；尚未被 SwiftUI 下一次渲染确认的写入临时缓存在桥内，确认后清除，以免连续按键或检查器读取旧快照。每次有效编辑注册一个原生 `UndoManager` 逆操作；撤销同时注册重做。每个文档编辑器持有一个 Foundation UndoManager，只记录曲谱编辑的逆操作；Canvas 第一响应者、曲谱快捷键和工具栏调用它。FileDocument 窗口自身的管理器继续负责其内部记账及文本字段的原生编辑流程；曲谱编辑器不会采用它，避免逆操作写回文档后的延迟记账清空曲谱重做栈。两者始终读写同一个 FileDocument Binding，没有第二份曲谱历史模型。文本字段获得焦点时仍使用其原生文本撤销。候选值先通过 `ScoreValidator`，错误时保持当前曲谱并显示原因。悬空延音属于可见警告，允许先录延音起点再录目标。

录入：点击谱面选择弦和时间位置，数字输入 0–24 品（连续两位输入窗口 0.8 秒）。同一时间在不同弦输入会合成一个和弦事件。左右键按当前事件时值移动，上下键换弦，Tab 换声部，Return 前进。W/H/Q/E/S/T 选择全音符至三十二分；`.` 附点，R 休止，L 延音，⌫ 删除当前弦音符，⌘C/⌘V 复制粘贴完整事件，⌘X 剪切完整事件，⌘Z/⇧⌘Z 撤销重做，空格播放暂停。

以下录入与定位行为适用于第一行选择“曲谱合成”时。编辑选择与播放位置分别保存。点击音符或弦内时间位置会进入编辑并同步顶部进度条；播放中选音会先暂停再定位。空格或播放按钮成功启动后取消编辑高亮；暂停后重新选音会从新位置开始，没有重新选择时则从暂停处继续。点击谱面空白或按 Esc 取消编辑选择，保留已设置的播放位置；无选择时数字、删除、剪切、粘贴和音符检查器不会修改原来的音符。方向键在无选择时先从当前播放位置的合法录入网格恢复编辑，之后再按原有规则移动。拖动进度条仅定位播放并取消选择，精确位置不被录入网格吸附，正在播放时继续播放；重新选中谱面后才能录入。

两声部独立计时，旋律蓝色符干向上，低音橙色符干向下。当前音符可在检查器中设置技巧、目标品位、力度和单音延音。和弦中部分音持续使用短时值分段并对需要持续的弦设置延音；另一个声部可同时保持整小节低音。浅色休止表示空余时值，显式休止使用声部颜色。

时值工具栏同一行的“每行”可选自动、1、2、4 小节；固定数量不受右侧检查器开关影响。自动模式按整谱最密集小节的排版宽度选择列数，保证统一列宽。旁边的“缩放”同步放大数字、弦距、技巧及歌词；窄窗口中改用百分比菜单，保持工具栏为一行。单小节超过可用宽度时仍可横向滚动，选择和播放会定位到当前音符。

点击下方“联动指板”旁的向下箭头可收起指板，释放高度给谱面；折叠后保留标题栏，点击向上箭头即可展开。每行小节数和指板显示状态保存在本机偏好中，下次打开仍采用上次选择，不写入曲谱文档。

联动指板右侧的“演奏提示”随播放、暂停定位或谱面选择更新，显示所选声部的前句、当前歌词和后句，以及前一、当前和下一和弦。歌词按已有标点、换行和停顿组织为片段；原文件只有逐音歌词时不补写歌词，也不猜测单个事件内部的字词时间。长句悬停可查看全文。和弦读取两声部歌词中的 `[Em]`、`[Fmaj7]`、`[C/G]` 等明确标记，同一时刻优先采用所选声部；无标记时显示空状态，不根据一小节混合音高猜和弦。

后续段落按实际演奏顺序继续录入到后续小节；同一事件的换行只是文字排版，不代表新的演奏时间。

顶部进度条旁显示曲谱 BPM 下的位置与总时长；变速保持同一曲谱时间坐标。原声音频的前奏、自由速度或编配差异仍需要单独对齐，曲谱时间不等于自动匹配的录音时间。

在提示区选择“参考调”可查看三个和弦的罗马数字级数，例如 E 小调的 Em → C → G 显示 i → VI → III。参考调由用户选择，不自动推断；按谱面和弦标记使用的调性选择，变调夹整体移调不改变相对级数。这个选择属于当前文档窗口的显示状态，不改变谱面音高或文件格式。

播放、暂停、停止、定位、变速、节拍器、预备拍、声部静音与循环均调用共享 `AudioService`，每文档使用独立 owner ID；录入试听使用独立的 preview owner，不会把单音试听误认为完整曲谱播放。谱面游标、活动事件和下方 24 品指板同步。循环范围可从检查器选择，也可右键小节设为开始或结束。“跟练”打开共享练习面板，进入前停止本文档示范播放。

预备拍期间重新选音同样暂停并取消预备拍，随后从新位置继续。有效改谱、撤销和重做会停止本文档的旧播放会话，下次播放使用最新曲谱；播放验证失败保留当前选择和目标位置。联动指板下方不再显示整条编辑状态栏，指板标题也不重复显示弦位与 ticks；音频设备和采集状态仍由底部音频状态栏显示。

键盘能力仅通过 `NSViewRepresentable` 包装一个原生 `NSView` 加入响应者链；Canvas、文档值、选择和检查器均由 SwiftUI 管理。键盘桥在谱面点击后请求第一响应者，不在文字输入期间拦截全局键盘。

## 统一音频与演奏模式

第一行的音频选择器提供“曲谱合成”“无伴奏演奏”和当前曲库条目的附加音频。播放、暂停、停止、从头和进度共用同一行。附加音频预载后显示真实录音时长，选择本身不播放；其进度条和变速只控制录音。Apple Music 链接仍在“我的曲库”打开。

选择附加音频或无伴奏演奏即进入演奏模式：检查器改为只读，隐藏录谱与循环控制；谱面、歌词、指板点击不试听、不选音、不定位。数字、方向键、剪切粘贴和撤销重做不会改谱，空格仍播放／暂停。切回“曲谱合成”恢复编辑，保留原曲谱及编辑历史。

开始演奏后使用麦克风或声卡输入跟随所选声部，不使用系统声音来匹配伴奏自身。`ScoreFollower` 根据可信单音持续约 120 ms 的证据确认谱位；同音重复必须有新的拨弦起音。错音、静音和单纯经过时间不会推进；漏掉少量音符后，最多向前查看三个可识别音，并以两个连续音的证据恢复位置。谱面、歌词提示和指板随确认的谱位滚动，附加音频时间不映射为谱位。休止符和连音不会要求重复拨弦；和弦、死音及连续变音技巧暂不独立识别，等待后续可识别单音重新定位。使用麦克风时建议戴耳机，避免录音从扬声器串入输入。

`PlaybackCoordinator` 在同一进程内同步移交音频输出，曲谱、学习室试听、调音参考和附加音频最多只有一个正在播放。另一个窗口开始播放会暂停旧音频并保留位置；演奏会话也先暂停旧窗口，再取得声音输入。

## 编辑状态回归验证

本次统一播放与演奏模式通过 173 项单元测试、39 项 QA 应用原生检查及实际窗口检查。新增 `ScoreFollowerTests` 覆盖稳定音、重复音起音、漏音恢复、静音/错音及暂停恢复；`runScorePerformanceChecks()` 覆盖只读边界与编辑历史恢复；`ReferenceAudioChecks` 验证实际播放器的互斥接管、暂停位置、变速、结束与重播。日志为 `artifacts/tests-performance.log`、`artifacts/app-self-check-performance.json`。真琴环境中的跟随效果仍需实际弹奏验证。

`runScoreEditorChecks()` 与异步 `runScoreEditorDelayedUndoCheck()` 使用实际 `ScoreEditorState`、文档 Binding 和 macOS `UndoManager`，覆盖两个独立声部、原生撤销/重做、同弦和超容量拒绝、两位品位、JSON 重开，以及先录起点的和弦单音跨小节延音、静音后的联动高亮。选择回归还覆盖取消选择后的旧位置写入保护、同点重复选择、数字组合清理、方向键恢复编辑，以及四种拍号下的精确播放定位与合法录入网格。异步撤销用例模拟逆操作写回后延迟到达的文档记账，确认等待后仍能重做。

`runScoreTransportChecks()` 使用 QA 进程中空闲的实际 `AudioService` 和输出 renderer，连续三轮验证“选择 A → 播放 → 暂停 → 选择 B → 播放”，并检查无重选续播、播放中选音、拖动进度条、暂停后指板试听的位置保留、多文档音频归属、预备拍中重选、修改后丢弃旧曲谱快照和播放失败保留选择。检查期间静音两个曲谱声部，结束或抛错时停止测试播放并恢复原播放设置。这些检查不代替实际窗口中的键盘焦点、空白点击、视觉布局或真琴验收。

从最终 `.app` 重新记录这些检查（构建脚本会先正常关闭旧应用）：

```sh
./script/build_and_run.sh --build-only
open dist/Guitarget.app --args --self-check "$PWD/dist/editor-self-check.json"
cat dist/editor-self-check.json
```

输出的 `passed` 应为 `true`，`checks` 包含本次执行的编辑、真实音频播放及其他原生检查结果。也可运行 `./script/stage_qa.sh`，使用独立的 `Guitarget QA.app` 并读取 `artifacts/app-self-check.json`；运行前应正常退出旧 QA 应用。

撤销诊断使用公开 OSLog 字段，可读取管理器身份、注册状态和分组：

```sh
/usr/bin/log show --last 5m --style compact --predicate 'subsystem == "com.guitarget.mac" AND category == "EditorUndo"'
```
