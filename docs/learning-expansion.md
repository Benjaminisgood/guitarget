# 和弦、调音与合奏

这四个栏目与原有五个栏目同处原生学习室，使用共享音频服务。无需网络、第三方包或商业录音。硬件采集沿用“声音来源”，关闭采集时仍可浏览、试听、合奏和自评。

## 和弦库

选择根音与和弦类型，再设置按弦品位范围、最高与最低按弦品差、发声弦数、空弦、横按和根音低音条件。查询对这个明确的模型穷举，结果分页显示；相同弦品仅保留一组最少用指方案。空弦是否允许独立于按弦范围。

支持大、小、属七、大七、小七、挂二、挂四、减、增、减七、半减七、大六、小六、加九和属九。构成音必须全部出现，不暗中省略五音等音；因此较严格的筛选可能没有结果。选择更宽的品位或弦数条件后重新查询即可。

指法使用左手 1–4 指，允许一指按单点或同品连续横按；横按能跨更高品按弦，不能跨消音、空弦或较低品。模型不包括拇指、反手和人体关节、弦距等条件。这里的“全部”指筛选与模型内的弦品组合，候选是否舒适仍需实际试按。

## 调音器

- 色度：匹配最近的十二平均律半音。
- 自动目标弦：按频率匹配当前调弦中最接近的空弦，须在 ±250 音分范围内。
- 锁定弦：点击某个空弦目标，只显示相对该弦目标的偏差；可直接观察错八度或大幅失谐。

预设包括标准、Drop D、DADGAD、降半音、开放 G、开放 D、开放 E。参考 A4 可按 0.5 Hz 步长调整，默认 440 Hz；目标频率与合成参考音同时遵守此基准。参考音播放期间暂停本页读数，结束后留出短暂衰减时间。

稳定性由连续有效频率重新计算，不把单个检测结果直接标为调准。读数过期、输入关闭或条件切换后清空；图表保留最近八秒的有效偏差。弦号仅是匹配或锁定的目标，不代表系统知道实际弹了哪根弦。调音器设置不会修改已打开的曲谱。

## 合奏

内置编配均由 Swift 生成，可保存为普通 `.guitarget` 曲谱：

| 伴奏 | 和弦进行 | 编配 |
| --- | --- | --- |
| 民谣分解 | I–V–vi–IV | 八分分解与根音／五音低音 |
| 流行切分 | I–V–vi–IV | 切分和弦与二分低音 |
| 小调慢板 | i–VI–III–VII | 留白分解与整小节低音 |
| 十二小节布鲁斯 | I7–IV7–V7 | 直八分节奏、闷音和弦、低音律动 |

1. 选择根音、伴奏与 BPM，点击“开始合奏”。可启用循环、预备拍、节拍器。
2. 和弦卡片由真实播放 ticks 定位，点击卡片可跳至相应小节。
3. 初学先选“当前和弦音”，在第一拍弹根音。再用五声音阶写短句，并在和弦音上结束。
4. 伴奏中点击指板选择目标音。“暂停伴奏并试听”会听完后从原位置返回；直接弹真琴无需中断伴奏。
5. “生成当前推荐音练习谱”把这组音保存为单音上下行练习，之后可在原有曲谱跟练中练习。

旋律声部为 1–4 弦的和声，低音声部为 5–6 弦，使用同一音频时钟。合奏的循环、预备拍、节拍器和静音设置限于本次播放，不改动其他文档的全局播放设置。转调与速度在停止后修改；普通文档变速仍由原来的播放工具栏控制。

推荐音是创作指导，自由合奏不评分。布鲁斯五声音阶和蓝调音可能与大三度形成张力；不能把所有推荐音解释为每个时刻都同样稳定。麦克风与扬声器同时使用可能有串音，伴奏练习建议佩戴耳机。

## 和弦练习

选择根音集合、大／小和弦与轮数。看图模式直接显示按法；听示范模式先隐藏图示，听完分解后复现；记忆模式在倒计时结束后隐藏图示。可揭示提示、再次试听或跳过，结果保留是否使用提示。

逐弦检查按低音到高音逐根演奏；拨下一根前先消掉上一根的余音，每根要求新的起音与稳定单音。检查只证明依次出现了目标音高，不能判断真实弦位、同时发声的和弦或整体扫弦质量。关闭采集、示范与其他播放期间不判定；手动跳过不会记为自动通过。

扫弦可用“清晰、熟练”“还需练习”或“跳过本轮”自评。自动通过弦数和自评轮数分别显示，不提供复音和弦识别准确率。

## 验证范围

新增算法的测试和原生操作结果记录在 [验收记录](acceptance.md)。历史真琴校准为 +4 ms，包含人为跟拍偏差；尚未把该偏移下的新一轮演奏当作已通过。新页面可运行和离线测试通过，均不替代当前包麦克风、系统采集和真人演奏的验收。
