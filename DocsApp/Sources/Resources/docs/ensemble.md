# 合奏

合奏栏目提供四种**原创双声部吉他伴奏**，由 Swift 代码生成（无商业录音），支持转调、速度、循环、小节定位和预备拍；播放时按当前和弦显示推荐音，并可一键生成单音练习谱接入跟练。

## 四种伴奏

| 伴奏 | 和弦进行 | 编配 | 默认 BPM |
| --- | --- | --- | --- |
| 民谣分解 | I–V–vi–IV | 八分分解与根音／五音低音 | 80 |
| 流行切分 | I–V–vi–IV | 切分和弦与二分低音 | 100 |
| 小调慢板 | i–VI–III–VII | 留白分解与整小节低音 | 68 |
| 十二小节布鲁斯 | I7–IV7–V7 | 直八分节奏、闷音和弦、低音律动 | 92 |

旋律声部为 1–4 弦的和声，低音声部为 5–6 弦，两个声部使用**同一音频时钟**——它们永远对齐，不会出现伴奏漂移。

## 使用流程

1. 选择**根音、伴奏与 BPM**，点击"开始合奏"；可启用循环、预备拍、节拍器。
2. **和弦卡片**由真实播放 ticks 定位（不是估算时间），点击卡片可跳至相应小节。
3. 初学者先选推荐音模式"**当前和弦音**"，在每个和弦的第一拍弹根音；熟练后用五声音阶写短句，并在和弦音上结束乐句。
4. 伴奏播放中**点击指板**选择目标音；"暂停伴奏并试听"会听完后从原位置返回；直接弹真琴无需中断伴奏。
5. 点击"**生成当前推荐音练习谱**"，把这组音保存为单音上下行练习曲谱，之后在曲谱跟练中练习。

## 推荐音三档

| 模式 | 内容 | 适合 |
| --- | --- | --- |
| 当前和弦音 | 只推荐当前和弦的构成音 | 建立"落在和弦内"的听感 |
| 五声音阶 | 当前把位的五声音阶音 | 即兴短句 |
| 调内音阶 | 整个调的音阶音 | 进阶色彩，注意张力音 |

推荐音随小节和调性正确拼写音名。

## 行为边界

- **转调与速度在停止后修改**；播放中不改调性和 BPM。
- 合奏的循环、预备拍、节拍器和静音设置**限于本次播放**，不改动其他文档的全局播放设置。
- 推荐音是**创作指导，自由合奏不评分**——没有"弹错"一说。
- 布鲁斯五声音阶和蓝调音可能与大三度形成张力；不能把所有推荐音解释为每个时刻都同样稳定。
- 麦克风与扬声器同时使用可能有串音，**伴奏练习建议佩戴耳机**。
- 切换栏目会停止本模块播放（全应用互斥播放）。

## 保存为你的曲谱

内置编配均可保存为普通 `.guitarget` 曲谱：点击"**打开伴奏曲谱**"生成文档，原生 ⌘S 保存。保存后的文件与手工录谱完全等价——十二根音、完整和弦音、双声部弦位隔离都有自动化测试覆盖（4 项伴奏编配测试 + 2 项播放选项测试）。

QA 验收曾从 C 民谣分解生成并保存四小节、80 BPM、melody/bass 两声部的文档，回读一致。

## 即兴练习建议

1. **第一周**：只用"当前和弦音"，每小节弹根音 + 一个和弦音，跟住和弦卡片切换。
2. **第二周**：五声音阶模式，每个和弦内用 2–3 个音构成动机，在强拍落和弦音。
3. **第三周**：布鲁斯伴奏 + 小调五声，尝试蓝调音（♭5）作为经过音。
4. 随时用"生成练习谱"把顺手的乐句固化成曲谱，接跟练打磨时值。

> **提示**：合奏的音频时钟与曲谱播放同源（`AudioService` 共享实例 + ownerID 接管）。开始合奏会自动暂停其他窗口的播放并保留其位置，回来时从原处继续。
