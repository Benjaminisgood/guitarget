# 产品概览与设计理念

Guitarget 是一款**纯 Swift 原生 macOS 吉他学习应用**，把双声部六线谱与歌词编辑、本地曲库、钢弦吉他物理合成、单音跟练评分、复音和弦识别、调音器、CAGED 指型、和弦库与合奏伴奏整合进一个没有任何第三方依赖的原生程序。本文介绍它是什么、为什么这样做，以及整套文档的组织方式。

## 一句话认识 Guitarget

> Guitarget = 原生文档式六线谱编辑器 + 十个学习栏目 + 自研吉他音频引擎。曲库完全离线，Apple Music 链接交给系统"音乐"应用打开。

技术栈是 SwiftUI / AppKit、AVAudioEngine 与 CoreAudio process tap；**没有 WebView、没有 Python、没有外部运行时、没有第三方包、没有训练模型权重**。识别与合成算法全部用原生 Swift 手写实现，包括自研 FFT、YIN 音高检测和 NNLS 和弦分解。

## 功能全景

学习室侧栏包含十个栏目，另有原生多窗口曲谱文档：

| 栏目 | 定位 | 核心能力 |
| --- | --- | --- |
| 指板 | 认识每一个音 | 点击试听；音名／音级、根音高亮、15／24 品切换；识别结果按 MIDI 音高高亮所有位置 |
| 音阶 | 连接五种指型 | 12 根音 × 6 类音阶，全指板或 CAGED 五型，上下行试听或生成独立曲谱文档 |
| CAGED | 形状与和弦 | 实际根音 + 大／小和弦 + 形状，显示空弦、消音、指法与琶音，附简化按法说明 |
| 三和弦 | 听见调内和声 | 选择大调及 I–vii° 级数，在指型内标出根、三、五音，试听并生成练习谱 |
| 和弦库 | 查找适合的按法 | 12 根音 × 15 种和弦类型，按品位、跨度、弦数、空弦、横按、根音低音穷举按法 |
| 调音器 | 听准每一根弦 | 色度／自动目标弦／锁弦三模式，七种调弦预设，A4 400–480 Hz 基准与参考音 |
| 和弦识别 | 听出你弹的和弦 | 扫弦实时显示和弦名（含 C/E 转位低音）、构成音、音级能量、音准偏差与候选 |
| 合奏 | 跟着和声即兴 | 四种原创双声部伴奏，支持转调、速度、循环、小节定位、预备拍与推荐音 |
| 和弦练习 | 看、听、记住和弦 | 看图／听示范／限时记忆三种训练，逐弦单音、整和弦识别或纯自评三种判定 |
| 曲谱 | 写下你的音乐 | 原生文档窗口：双声部六线谱、逐事件歌词、我的曲库、音频绑定与跟练 |

## 设计理念

### 纯原生，拒绝黑盒

整个应用只链接 Apple 系统框架：

- **界面**：SwiftUI 场景 + AppKit 原生文档体系（`DocumentGroup`、`FileDocument`、`UndoManager`），六线谱用 Canvas 逐音符绘制，键盘输入通过一个小型 `NSView` 桥接入响应者链。
- **音频**：AVAudioEngine 渲染自研钢弦物理模型（Karplus–Strong 分数延迟线），采集同时支持麦克风 input tap 与 CoreAudio process tap（系统声音）。
- **算法**：YIN 音高、起音检测、FFT、NNLS 非负最小二乘、隐马尔可夫滤波全部为手写 Swift，无 Accelerate 之外的第三方依赖，无神经网络权重。

这带来几个直接好处：启动快、内存小、行为可审计（所有算法可以在 `Sources/` 里逐行阅读），也不存在 WebView 或脚本引擎带来的安全与维护面。

### 本地优先，联网为零

- 曲库、音频副本、歌词、Apple Music 链接全部保存在 `~/Library/Application Support/Guitarget/MyLibrary/`，应用本身不发起任何网络请求。
- Apple Music 链接只做本地保存，点击"在音乐中打开"时交给系统原生"音乐"应用，播放、订阅与版权完全由苹果的系统应用处理。

### 开放文档格式

`.guitarget` 是**版本化 UTF-8 JSON**，四分音符恒为 960 ticks，不以浮点秒保存谱面。格式完整公开（见《.guitarget 曲谱格式》一篇），AI 或脚本可以直接生成合法曲谱；应用打开时执行与人工录谱完全相同的结构与乐理校验。

### 诚实的验证文化

项目文档明确区分三类证据：离线算法测试、原生窗口操作记录、真琴实测。自动化测试通过不会被表述为"真琴准确率"；没有物理测量时不报告虚构的延迟或精度。`docs/acceptance.md` 甚至保留了历史失败记录（如系统采集启动超时），不因后续修复而删除。

## 明确不做的事

| 不做 | 说明 |
| --- | --- |
| 多乐器轨 | 只有本地六弦吉他的双声部 |
| Guitar Pro 导入 | 不支持 GP3/GP5 等第三方谱面格式 |
| 自动转谱 | 不把音频自动转写为曲谱 |
| 逐音复音评分 | 跟练只判定单音；和弦、死音、连续变音技巧明确跳过 |
| 下载 Apple Music 音频 | 不获取受保护内容，不做原声与谱面自动同步 |

## 代码结构速览

| 路径 | 职责 |
| --- | --- |
| `Sources/GuitarCore` | 乐理、唯一 `GuitarScore` 模型、ticks、校验、延音调度、跟练状态机（约 3100 行） |
| `Sources/GuitarAudio` | 六弦 DSP、音频时钟、采集设备、process tap、YIN、FFT／NNLS 和弦识别（约 2200 行） |
| `Sources/Guitarget` | SwiftUI 场景、原生文档、Canvas 六线谱、键盘桥接（约 7000 行） |
| `Tests` | 乐理、文档、调度、识别与练习回归，最新一轮 139 项 XCTest 全部通过 |
| `Examples` | 可直接打开的指弹、F 大调与技巧曲谱，以及纯 Swift 生成脚本 |
