# 曲谱跟练

跟练是曲谱文档的评分模式：启用输入后，Guitarget 听你弹的**单音**并逐目标判定。两种模式——"弹对再前进"（等待）与"按节拍跟练"（节拍）——共用同一套音高、起音与稳定性证据链。本文覆盖入口、判定参数、校准与边界。

## 入口与准备

- 学习页和曲谱工具栏都能打开练习面板；进入前会停止本文档的示范播放。
- 在窗口底部选择输入来源并**开始采集**（麦克风或外接声卡）。
- "按节拍跟练"默认启用**预备拍和节拍器**，两个声部静音（练习默认不播放目标及另一声部）。
- **示范试听期间暂停评分**；恢复时重新对齐音频起始时钟，并忽略旧分析窗——示范尾音不能直接"替你通过"下一个目标，等待模式要求一个新起音。

## 判定参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 音准容差 | ±25 音分 | 目标音高允许的偏差 |
| 稳定时长 | 120 ms | 连续帧变化小于 18 音分才计入稳定 |
| 起音容差 | ±150 ms | 节拍模式下相对拍点的窗口 |
| 分析宽限 | 350 ms | 仅允许延迟到达的分析结果使用其**原有起音时间**，不会扩大起音容差 |
| 最低置信度 | 0.75 | YIN 置信度门槛 |
| 最低 RMS | 0.002 | 输入能量门槛 |

结果分别记录**音高误差、起音时间、判定时间和相对拍点偏移**；抢拍／拖拍数字为实际有符号偏移。音高正确但超出容差显示抢拍或拖拍；完全无有效起音显示漏音。

## 判定规则

- **重复同音需要新起音**：连续两个相同目标音，第二次必须重新拨弦（起音检测有 90 ms 不应期，自然延音不会生成新起音）。
- **连线延音不重新评分**：明确 tie 的续音已在目标生成时合并。
- **明确跳过单音评分**：同声部和弦、死音、击弦、勾弦、滑音、推弦、揉弦。跳过不是失败，是算法的诚实边界。
- **等待模式**：弹对才前进；被跳过的目标可**手动继续**。
- **节拍模式**：按时间继续；检测到后续起音时可以结束前一漏音的等待，避免漏一个短音后阻塞整串目标。

## 跟拍校准

"跟拍校准"用你实际弹奏的多次起音估计输入偏移：

1. 跟随提示按拍弹奏，系统收集匹配的"预期起音／实际起音"对。
2. **中位数至少使用三组匹配**，每拍最多计一次。
3. 结果显示如"已用 8 次起音估计偏移：+4 ms（含人为跟拍偏差）"，输入延迟字段同步更新。

注意：校准值**包含人的跟拍误差**；精确的声卡硬件延迟需要物理回环测量。校准只接受其自身播放时钟的起音；采集断开、另一窗口接管、时钟或速度改变会取消校准；无法获得音频时钟会给出错误，而不是无限等待。

## 练习时钟与设置接管

- 练习面板持续跟随音频源节点发布的起始时钟：变速、输出设备切换和暂停恢复后的新时钟都会更新练习时间轴，**已评分结果保留**。
- 有效练习速度 = 曲谱 BPM × 播放倍率；超过 300 BPM 的变速结果不再被截回。
- 评分使用单调音频时钟锚点，**不使用按下播放按钮的时间**；重新定位和变速会建立新锚点。
- 其他窗口接管播放时暂停判定，临时归还原来的声部静音、速度和节拍设置，返回练习后恢复练习设置；练习结束只恢复一次先前的全局设置。

## 真琴验证状态

- 等待模式：低 E2 重复音"每次拨弦只推进一个"已通过真琴复测（修复了持续音误触发 31 个起音的旧缺陷）。
- 节拍模式：一轮八个 E2 目标 8/8 正确、平均起音偏差 35 ms（内置麦克风、未戴耳机、校准前）；八次起音校准得到 +4 ms。
- **尚未完成**：±25 音分与 ±150 ms 边界的受控实验、跨小节延音真琴验证、物理端到端输入延迟测量。详见 `docs/acceptance.md`。

## 练习建议

1. 佩戴耳机，避免扬声器串音进入麦克风。
2. 先跑一次跟拍校准，把系统偏移和跟拍习惯一起吸收掉。
3. 从 60–80 BPM 的等待模式开始，确认每个目标的起音干净。
4. 换节拍模式后关注逐音结果的**有符号偏移**：持续为正（拖拍）比绝对值大小更值得修正。
5. 和弦与技巧段落会明确跳过，不要在那里等待判定。

> **提示**：麦克风下的扬声器串音无法保证消除，这是算法文档里反复声明的边界。带声音练习请始终佩戴耳机。
