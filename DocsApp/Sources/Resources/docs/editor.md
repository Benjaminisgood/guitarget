# 六线谱编辑器与键盘输入全解

曲谱编辑器是 Guitarget 的核心：一个标准 macOS 原生文档窗口，承载双声部六线谱、逐事件歌词与全部播放控制。本文覆盖文档模型、录入流程、**全部快捷键**、检查器、延音处理与演奏提示。

## 原生文档模型

- `GuitarScoreDocument` 通过 SwiftUI `DocumentGroup` 接入原生新建、打开、保存、另存为、未保存状态与关闭确认；文件类型为 `com.guitarget.score` / `.guitarget`。
- 读写严格走 `GuitarCore.ScoreIO` 的 JSON 编解码；版本、节奏、声部、弦位和技巧校验失败会抛出原生打开错误，**读取过程不写原文件**。
- 文件菜单"复制"或按住 Option 后的"存储为"可另存副本。
- 每次有效编辑向该文档专属的 Foundation `UndoManager` 注册一个逆操作；撤销同时注册重做。文本字段获得焦点时使用它自己的原生文本撤销，与曲谱历史互不污染。
- 候选值先过 `ScoreValidator`：容量超限、同声部事件重叠、同弦跨声部持续音冲突、错误技巧目标都是错误，保存和修改会被**拒绝并显示原因**，不移动另一声部、不截断音符。

## 录入流程

1. **点击谱面**选择弦和时间位置，进入编辑选择（同时同步顶部进度条）。
2. **输入品位** 0–24；两位数在 **0.8 秒**内自动组合（先按 `1` 再按 `2` 得到 12 品）。
3. 同一时间在不同弦输入音符会合成一个**和弦事件**。
4. 用方向键移动、`Tab` 切换声部、`Return` 前进，继续录入。
5. 播放中选音会先暂停再定位；空格或播放按钮成功启动后取消编辑高亮。

### 选择与定位的边界行为

| 操作 | 结果 |
| --- | --- |
| 点击音符或弦内时间位置 | 进入编辑选择并同步进度条；播放中先暂停 |
| 点击空白处或按 `Esc` | 取消编辑选择，但**保留已设置的播放位置** |
| 无选择时按方向键 | 先从当前播放位置的合法录入网格恢复编辑选择，再按原规则移动 |
| 无选择时输入数字、Delete、剪切、粘贴 | 不修改任何音符 |
| 拖动进度条 | 仅定位播放并取消选择；精确位置不被录入网格吸附；播放中继续播放 |
| 暂停后重新选音 | 从新位置开始播放；未重新选择则从暂停处继续 |

以上录入与定位行为适用于第一行选择"曲谱合成"时；选择附加音频或无伴奏演奏会进入只读演奏模式（见《我的曲库与音频绑定》）。

## 快捷键总表

### 品位与导航

| 按键 | 功能 |
| --- | --- |
| `0`–`9` | 输入品位 0–24，两位数字在 0.8 秒内组合 |
| `←` `→` | 按当前事件时值前后移动 |
| `↑` `↓` | 换弦 |
| `Tab` | 切换旋律／低音声部 |
| `Return` | 前进到下一位置 |
| `Esc` | 取消编辑选择 |

### 时值与事件

| 按键 | 功能 |
| --- | --- |
| `W` | 全音符 |
| `H` | 二分音符 |
| `Q` | 四分音符 |
| `E` | 八分音符 |
| `S` | 十六分音符 |
| `T` | 三十二分音符 |
| `.` | 附点（时值 × 3/2） |
| `R` | 休止 |
| `L` | 延音（tie 到下一音） |
| `Delete` / `⌫` | 删除当前弦的音符 |

### 编辑与播放

| 按键 | 功能 |
| --- | --- |
| `⌘C` / `⌘V` | 复制／粘贴完整事件 |
| `⌘X` | 剪切完整事件 |
| `⌘Z` / `⇧⌘Z` | 撤销／重做（另有工具栏与原生"编辑"菜单两条等价路径） |
| `空格` | 播放／暂停 |
| `⌘S` | 保存（曲库文档保存回曲库内） |
| `⌘N` `⌘O` `⌘W` `⌘Q` | 原生新建、打开、关闭窗口、退出 |

键盘能力通过 `NSViewRepresentable` 包装一个原生 `NSView` 加入响应者链：Canvas、文档值、选择和检查器都由 SwiftUI 管理；键盘桥在谱面点击后请求第一响应者，**不在文字输入期间拦截全局键盘**。

## 双声部与和弦

- 两个声部**独立计时**，均使用同一小节起点；旋律蓝色符干向上，低音橙色符干向下。
- 同拍多弦组成一个和弦事件；同声部和弦必须写在同一事件的 `notes` 数组内，不能写成重叠事件。
- 和弦中只有一根弦需要延长时，把事件**拆成相邻时段**：仅给该弦勾选"延音至下一音"（`tieToNext`），下一事件重复该弦同品音符；续音的技巧必须为 `none`。另一个声部可以同时保持整小节低音。
- 尚未录入续音的延音显示**悬空警告**，允许先录延音起点再录续音；播放只持续已明确记谱的时值，不猜测续音。
- 多段延音在播放调度中合并为一次拨弦；跨小节延音只触发一次拨弦。

## 检查器

选中事件或音符后，检查器提供：

| 分组 | 可编辑项 |
| --- | --- |
| 音符 | 技巧（普通、击弦 H、勾弦 P、滑音 /、半音推弦 ½、全音推弦 1、揉弦 ~、闷音 P.M.、死音 ×）、目标品位（击弦／勾弦／滑音必填）、力度 0–1、单音延音开关 |
| 事件 | 歌词（见《歌词编辑》） |
| 文档 | 拍号（2/4、3/4、4/4、6/8）、速度 BPM（20–300，默认 80）、循环小节起止 |

循环范围也可在谱面上**右键小节**设为循环开始或结束。

## 排版控制

- **每行**：自动／1／2／4 小节。自动模式按整谱最密集小节的排版宽度选择列数，保证统一列宽；固定数量不受检查器开关影响。
- **缩放**：同步放大数字、弦距、技巧标记与歌词；窄窗口中改用百分比菜单。
- **联动指板**：可折叠，折叠后保留标题栏；每行小节数和指板显示状态保存在本机偏好。
- 附点休止符按基础时值选择图形、附点独立绘制；密集谱中品位数字、符尾和 PM 标记互不覆盖。

## 演奏提示与参考调

联动指板右侧的**演奏提示**随播放、暂停定位或谱面选择更新：

- 显示所选声部的**前句、当前歌词和后句**；歌词按已有标点、换行和停顿组织为片段，原文件只有逐音歌词时不补写、不猜测事件内部字词的时间。长句悬停可查看全文。
- **和弦**读取两声部歌词中 `[Em]`、`[Fmaj7]`、`[C/G]` 等明确标记，同一时刻优先采用所选声部；无标记时显示空状态，**不根据一小节混合音高猜和弦**。
- 选择"参考调"可查看三个和弦的罗马数字级数，例如 E 小调的 Em → C → G 显示 i → VI → III。参考调由用户选择、不自动推断；变调夹整体移调不改变相对级数。这个选择只是当前窗口的显示状态，不改变谱面音高或文件格式。

## 播放控制

- 播放、暂停、停止、定位、变速、节拍器、预备拍、声部静音与循环均调用共享 `AudioService`，每个文档使用独立 owner ID；单音录入试听使用独立 preview owner，不会被误认为整谱播放。
- 谱面游标、活动事件和下方 24 品指板同步；UI 游标以 30 Hz 从音频样本计数读取。
- 变速重新计算 ticks/sample，**不改变拨弦频率**（变速保持音高）；顶部进度条旁的总时长按当前 BPM 换算，变速保持同一曲谱时间坐标。
- 预备拍期间重新选音同样会暂停并取消预备拍，随后从新位置继续；预备拍不推进谱面游标。
- 有效改谱、撤销和重做会停止本文档旧播放会话，下次播放使用最新曲谱；播放验证失败时保留当前选择和目标位置。
- **跟练**按钮打开共享练习面板，进入前停止本文档示范播放（详见《曲谱跟练》）。

> **提示**：录一条完整的指弹小节——低音声部先按 `Tab` 切过去，输入第 6 弦品位并用 `H`（二分）+ `L`（延音）铺满整小节；再切回旋律声部用 `E` 录八个八分音。这正是 `Examples/Fingerstyle.guitarget` 的结构。
