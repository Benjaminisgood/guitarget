# 我的曲库与音频绑定

"我的曲库"是 Guitarget 的本地内容中心：你自己的曲谱、逐事件歌词、绑定的原声音频与 Apple Music 链接都保存在这里，完全离线。本文覆盖曲库管理、六份入门谱、数据存储、音频绑定与只读演奏模式。

## 打开曲库

从学习室的 **曲谱 → 我的曲库** 打开管理弹窗。首次使用会自动加入六份自编入门谱（全部标准调弦）：

| 曲目 | 内容 | 练习方法 |
| --- | --- | --- |
| 半音爬格子 | 1–2–3–4 半音爬格子，12 小节，60 BPM | 从第 6 弦走到第 1 弦再以 4–3–2–1 返回；左手食指至小指依次对应 1–4 品，右手交替拨弦，每拍一音 |
| C 大调音阶 | 单八度上下行，4 小节，60 BPM | 实音 C3–C4–C3，注意换弦与均匀节拍，最后一个 C 保持两拍 |
| 分解和弦 | C–Am–Fmaj7–G 两轮共 8 小节，60 BPM | 每小节八个八分音符，右手 p–i–m–a–m–i–m–i；Fmaj7 只拨 4、3、2、1 弦，无需横按 |
| 《小星星》 | 完整常见旋律，12 小节，72 BPM，英语歌词 | 先练旋律，再按事件下方音节轻唱；短横线表示一个词拆成多个音节 |
| 《欢乐颂》 | 贝多芬主题前 8 小节，72 BPM | 单音旋律，练习重复音与"附点四分＋八分＋二分"节奏 |
| 《Frère Jacques》 | 传统旋律 8 小节，72 BPM，法语歌词 | 对照歌词练四分、八分与二分音符；末两小节的 G 用第 6 弦 3 品 |

经典旋律及所用历史歌词为公版，编配由本项目独立编写，未附商业录音。可导入副本在 `Examples/MyLibrary/`，同目录附练习指导。

## 曲库管理操作

| 操作 | 说明 |
| --- | --- |
| 搜索 | 按名称过滤列表 |
| 新建 | 创建空白曲库条目 |
| 批量导入 | 选择 `.guitarget` 或曲谱 JSON 文件导入副本 |
| 重命名 | 修改**管理用名称**；谱内标题仍由编辑器修改，两者独立 |
| 打开编辑 | 打开原生文档窗口；按 ⌘S 保存后修改留在曲库内 |
| 导出 | 普通导出**只包含谱和歌词**；音频副本与 Apple Music 链接属于本机曲库，不打包 |
| 移除 | 需先保存并关闭该曲库文档窗口 |

外部或未保存文档可用编辑器工具栏的**存入我的曲库**保存当前内容的新副本。

## 数据存储位置

```text
~/Library/Application Support/Guitarget/MyLibrary/
├── library.json                 # 曲库目录（清单）
└── <每条曲目的 UUID 子目录>/
    ├── score.guitarget          # 曲谱 JSON
    └── <绑定的音频副本>          # 可选
```

- 弹窗底部可**在 Finder 中显示**该目录。
- **备份应复制整个 `MyLibrary/` 目录**；恢复时放回同一路径。
- QA 实例使用独立的 `Guitarget QA/MyLibrary/`，与主应用数据互不干扰。

## 绑定原声音频

在曲库详情中**选择音频文件**，绑定自己的原声、伴奏或录音：

1. 支持系统可解码的格式：MP3、M4A、AAC、WAV、AIFF、CAF、FLAC、ALAC。
2. 音频**复制到曲库**内；源文件之后被移动或删除都不影响播放。
3. 请只绑定你已有使用权的文件；商业录音有独立于公版旋律的权利。

## 播放模式与只读演奏

编辑窗口第一行的音频选择器提供三种来源，共用播放、暂停、停止和进度控制：

| 选择 | 行为 |
| --- | --- |
| 曲谱合成 | 正常编辑模式，钢弦模型实时合成谱面 |
| 无伴奏演奏 | 只读演奏模式，无合成伴奏，靠输入跟随谱位 |
| 附加音频 | 只读演奏模式，播放绑定的录音 |

选择附加音频或无伴奏演奏即进入**只读演奏模式**：

- 检查器只读，隐藏录谱与循环控制；谱面、歌词、指板点击不试听、不选音、不定位。
- 数字、方向键、剪切粘贴和撤销重做不会改谱；空格仍播放／暂停。
- 附加音频预载后显示真实录音时长；选择本身不播放，进度条和变速只控制录音。
- 切回"曲谱合成"恢复编辑，保留原曲谱及编辑历史。

## 智能跟随（ScoreFollower）

演奏模式下，谱面根据麦克风或声卡检测到的**单音**智能跟随：

- `ScoreFollower` 需要可信单音持续约 **120 ms** 的证据才确认谱位；同音重复必须有新的拨弦起音。
- 错音、静音和单纯经过时间**不会推进**；漏掉少量音符后，最多向前查看三个可识别音，并以两个连续音的证据恢复位置。
- 谱面、歌词提示和指板随确认的谱位滚动；**附加音频时间不映射为谱位**——录音的前奏、自由速度或编配差异不会被自动对齐。
- 休止符和连音不要求重复拨弦；和弦、死音及连续变音技巧暂不独立识别，等待后续可识别单音重新定位。
- 跟随可选旋律或低音声部；附加音频使用系统默认输出，全应用合成音与附加音频互斥播放。

> **提示**：使用麦克风跟随时务必佩戴耳机，否则伴奏会从扬声器串入麦克风，污染单音检测。

## 验证与边界

曲库功能有 12 项本地曲库测试、3 项歌词测试与 5 项入门谱测试覆盖（Unicode 歌词往返、音频绑定持久化、删除与失败回滚、路径和符号链接检查等）；损坏条目会被移除，重启不会重新添加已删除曲目。Apple Music 链接的行为见下一篇。
