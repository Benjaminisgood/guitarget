# 歌词编辑

Guitarget 的歌词是**逐事件**的：每个音符或休止事件可以挂一个字、词或音节，按事件位置对齐在六线谱下方，随播放高亮。本文覆盖编辑方法、显示规则、格式字段与兼容边界。

## 基本操作

1. 在谱面点击选中一个音符或休止事件。
2. 在检查器的**歌词**栏输入对应的字、词或音节。
3. 留空即移除歌词。

歌词支持完整的编辑能力：**撤销重做、复制粘贴、保存重开**都会保留；更改品位、时值或把事件转为休止时歌词同样保留。删除带歌词事件的最后一个音符时，事件先保留为**带歌词的休止**，再删除该休止即可移除整个事件。

## 显示与交互

| 行为 | 说明 |
| --- | --- |
| 对齐 | 歌词按事件位置对齐在六线谱下方 |
| 播放高亮 | 随谱面播放逐事件高亮，跟唱时视线不用离开谱面 |
| 点击选择 | 直接点击歌词可选中对应事件 |
| 长文字 | 自动换行；相邻文字碰撞时错行排列 |
| 缩放 | 歌词跟随工具栏"缩放"同步放大缩小 |

## 声部与休止

- **旋律与低音声部各自拥有歌词**，互不覆盖；同一和弦事件共用一份歌词。
- 显式休止也可以保留文字，常用来标注**换气**或段落提示。

## 和弦标记

歌词文本中的方括号标记会被演奏提示区读取为和弦：

- 支持 `[Em]`、`[Fmaj7]`、`[C/G]` 等明确写法；同一时刻优先采用所选声部的标记。
- 无标记时演奏提示显示空状态，**不会根据一小节内的混合音高猜和弦**。
- 标记只是文字，不影响播放与评分。

## 文件格式

歌词是 `.guitarget` 事件对象中的可选字符串字段 `lyric`：

```json
{
  "id": "E248F013-BF1D-4CE1-BB88-F68BCCF11002",
  "startTick": 0,
  "rhythm": {"value": 4, "dotted": false, "triplet": false},
  "lyric": "星",
  "notes": [ ... ]
}
```

- 省略 `lyric` 或设为 `null` 都表示没有歌词；**旧版没有歌词字段的曲谱无需转换即可打开**。
- 歌词原样保留 Unicode 与换行，不改变音符播放时间。
- 短横线约定：入门谱用短横线表示一个词拆成多个音节（如英语歌词）。

## 段落组织原则

编写或生成带歌词的谱面时：

1. 把后续段落和反复段**按实际演奏顺序**依次写入后续 `measures`，每段使用自己的歌词和新 UUID。
2. 数组顺序就是演奏顺序；同一事件内的换行只是文字排版，不代表新的演奏时间。
3. **不要**用同一事件的多行文字承载需要独立播放时间的不同段歌词。

演奏提示按已有标点、换行和停顿把歌词组织为片段显示前句／当前句／后句；原文件只有逐音歌词时不补写句子，也不猜测单个事件内部的字词时间。

## 示例谱

"我的曲库"的六份入门谱中有两份带完整歌词：

| 曲目 | 歌词 | 说明 |
| --- | --- | --- |
| 《Twinkle, Twinkle, Little Star》 | 英语 | 歌词取自 Jane Taylor 1806 年诗作《The Star》第一节，旋律与原文均为公版 |
| 《Frère Jacques》 | 法语 | 传统法国儿歌；"两只老虎"仅用于识别熟悉旋律，文件未收录中文改词 |

> **提示**：想给已有旋律配词，先在低音声部录整小节长音做伴奏，再逐事件填歌词；播放一遍检查高亮节奏是否和乐句呼吸一致，比事后微调快得多。
