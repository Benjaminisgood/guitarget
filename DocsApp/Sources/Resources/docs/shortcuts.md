# 快捷键速查

编辑器键盘能力通过原生 `NSView` 响应者链实现：**先点击谱面**让 Canvas 取得第一响应者，之后所有谱面快捷键生效；文字输入期间不会被拦截。文本字段内使用系统原生文本编辑快捷键。

## 品位与导航

| 按键 | 功能 |
| --- | --- |
| `0`–`9` | 输入品位 0–24；两位数在 0.8 秒内自动组合（`1` `2` → 12 品） |
| `←` | 后退一个当前事件时值 |
| `→` | 前进一个当前事件时值 |
| `↑` | 上一根弦 |
| `↓` | 下一根弦 |
| `Tab` | 切换旋律／低音声部 |
| `Return` | 前进 |
| `Esc` | 取消编辑选择（保留播放位置） |

无选择时：方向键先从当前播放位置的合法录入网格恢复编辑选择；数字、删除、剪切、粘贴不修改音符。

## 时值与事件

| 按键 | 时值 |
| --- | --- |
| `W` | 全音符 |
| `H` | 二分音符 |
| `Q` | 四分音符 |
| `E` | 八分音符 |
| `S` | 十六分音符 |
| `T` | 三十二分音符 |

| 按键 | 功能 |
| --- | --- |
| `.` | 附点（时值 × 3/2） |
| `R` | 休止 |
| `L` | 延音（tie 到下一音） |
| `Delete` / `⌫` | 删除当前弦的音符 |

工具栏提供全部常用时值按钮，与快捷键等价。

## 编辑

| 按键 | 功能 |
| --- | --- |
| `⌘C` | 复制完整事件 |
| `⌘V` | 粘贴完整事件（生成新 UUID） |
| `⌘X` | 剪切完整事件 |
| `⌘Z` | 撤销 |
| `⇧⌘Z` | 重做 |

撤销另有工具栏与原生"编辑"菜单两条等价路径，三者操作同一个文档级 `UndoManager`。

## 播放

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放／暂停（演奏模式下同样有效） |

循环、节拍器、预备拍、声部静音与变速在播放工具栏和检查器中设置；循环起止也可**右键小节**设定。

## 系统文档快捷键

| 按键 | 功能 |
| --- | --- |
| `⌘N` | 新建曲谱文档 |
| `⌘O` | 打开 |
| `⌘S` | 保存（曲库文档保存回曲库） |
| `⌘⇧S` | 存储为（文件菜单按住 Option 亦显示） |
| `⌘W` | 关闭窗口（未保存时弹原生面板） |
| `⌘Q` | 退出 |
| 打开最近使用 | 文件菜单 → 打开最近使用 |

## 排查

| 症状 | 处理 |
| --- | --- |
| 按键没反应 | 先点击谱面空白外的音符区域，让 Canvas 取得第一响应者 |
| 输入 12 只得到 1 | 两位输入窗口 0.8 秒，连续按 `1` `2`；超时后按 `2` 会覆盖为 2 品 |
| 撤销恢复了标题文字 | 文本字段有自己的原生文本撤销；点回谱面后 ⌘Z 才是曲谱历史 |
| 改不了谱 | 检查第一行是否选择了附加音频或无伴奏演奏（只读演奏模式），切回"曲谱合成" |
