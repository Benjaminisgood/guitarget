# 三和弦与和弦库

**三和弦**栏目把调内和声放进指型可视化，**和弦库**栏目对按法做条件穷举。两者共用同一套显式乐理数据，不依赖网络或第三方数据库。

## 三和弦

1. 选择一个大调（12 个根音）。
2. 选择级数 I–vii°，界面对应显示该级三和弦的性质：大三和弦（I、IV、V）、小三和弦（ii、iii、vi）、减三和弦（vii°）。
3. 在所选大调指型内高亮和弦的**根音、三音、五音**，逐音或整体试听。
4. **生成练习谱**：把当前和弦连接写成曲谱文档，接入编辑器与跟练。

三和弦使用 C 大调指型数据平移（见《指板、音阶与 CAGED》），因此你可以直观看到"同一个指型里藏着哪七个和弦"。

## 和弦库

和弦库回答的问题是："这个和弦在指板上**所有**能按的方式是什么？"它对明确的筛选模型做穷举，结果分页显示；相同弦品组合仅保留一组**最少用指**方案。

### 筛选条件

| 条件 | 说明 |
| --- | --- |
| 按弦品位范围 | 例如 0–5 品；空弦是否允许**独立于**按弦范围设置 |
| 最高与最低按弦品差 | 限制手型跨度，例如 ≤ 3 |
| 发声弦数 | 例如 4–6 根 |
| 空弦 | 是否允许空弦发声 |
| 横按 | 是否允许／要求横按 |
| 根音低音 | 最低发声弦必须是根音（排除转位） |

**构成音必须全部出现**，不暗中省略五音等音——因此较严格的筛选可能没有结果，选择更宽的品位或弦数条件重新查询即可。

### 指法模型

- 使用左手 **1–4 指**；一指可按单点，或同品**连续横按**。
- 横按能跨更高品的按弦，**不能跨消音、空弦或较低品**。
- 模型**不包括**拇指按弦、反手、人体关节角度与弦距等条件；"全部"指筛选与模型内的弦品组合，候选是否舒适仍需实际试按。

### 使用流程

1. 选择根音与和弦类型（默认 C 大三和弦显示 470 种候选、40 页，常用排序首项为 `x32010`）。
2. 收紧条件：例如开启"根音低音"后 C 剩 144 种；选 C9 并限根音低音得 38 种，构成音显示 C/E/G/B♭/D。
3. 分页浏览候选，每个按法显示弦品图与指法编号。
4. **逐音试听**（琶音）或**扫弦试听**整体效果；扫弦进入播放状态，与全应用互斥播放规则一致。
5. 找到满意的按法后，可到"和弦练习"栏目把它变成 drills（见《和弦练习模式》）。

## 测试覆盖

和弦库有 10 项 XCTest：用**独立有限范围暴力枚举**验证结果集合，检查全部构成音、转位、合法连续横按、最多四指、消音和边界条件；常用排序不删候选。排序曾因首项使用稀疏转位和弦、部分伴奏上下弦组合需要五指而返工修正——最终结果以完整通过为准。

> **提示**：和弦库的候选是"模型内穷举"，不是"人手推荐"。把品位范围压到实际把位（如 0–4）、跨度 ≤3、发声弦 ≥4，通常就能得到接近教材的常用按法列表。
