# 界面导览

Guitarget 有两类窗口：常驻的**学习室**主窗口和多窗口的**曲谱文档**。本文带你认识每个区域的位置与职责，之后各功能指南会深入细节。

## 学习室主窗口

学习室是应用的主入口，左侧栏目列表 + 右侧内容区。十个栏目一览：

| 栏目 | 副标题 | 用途 |
| --- | --- | --- |
| 指板 | 认识每一个音 | 全指板音符地图，点击试听，和弦识别结果同步高亮 |
| 音阶 | 连接五种指型 | 12 根音 × 6 类音阶的指型显示、试听与练习谱生成 |
| CAGED | 形状与和弦 | 五型和弦形状的空弦、消音、指法与琶音 |
| 三和弦 | 听见调内和声 | 大调 I–vii° 级三和弦在指型内的分布与试听 |
| 和弦库 | 查找适合的按法 | 条件穷举 12 根音 × 15 种和弦类型的全部候选按法 |
| 调音器 | 听准每一根弦 | 三模式调音、七种预设、参考音与偏差历史 |
| 和弦识别 | 听出你弹的和弦 | 扫弦实时识别，能量条、构成音与候选列表 |
| 合奏 | 跟着和声即兴 | 四种双声部伴奏 + 推荐音 + 练习谱生成 |
| 和弦练习 | 看、听、记住和弦 | 三种训练模式与三种判定方式的和弦 drills |
| 曲谱 | 写下你的音乐 | 打开"我的曲库"弹窗，或新建原生曲谱文档 |

学习室所有栏目共享同一个音频服务：切换栏目会停止上一栏目的播放，试听无需录音权限。

## 窗口底部状态栏

底部是全局**声音来源**与状态区：

- **输入来源**：无／麦克风或外接声卡／系统声音（process tap，可选整机混音或指定 App）。采集必须由用户点击"开始采集"显式启用。
- **输出设备**：与输入独立选择；播放走这里。
- **当前和弦**：和弦识别在任意栏目持续运行于状态栏，随时显示最近识别到的和弦或强力和弦。
- 使用麦克风同时播放伴奏时，界面会提示**佩戴耳机**，避免扬声器串入输入。

## 曲谱文档窗口

⌘N 新建或从曲库打开后，得到标准 macOS 文档窗口，自上而下：

1. **第一行：音频选择器 + 播放控制**。音频选择器提供"曲谱合成"、"无伴奏演奏"与当前曲库条目绑定的附加音频；播放、暂停、停止、从头与进度条共用同一行。顶部进度条旁显示当前 BPM 下的位置（ticks）与总时长。
2. **时值工具栏**：全音符到三十二分音符按钮、附点、休止、延音，以及"每行"（自动／1／2／4 小节）与"缩放"。窄窗口中缩放改为百分比菜单，工具栏始终保持一行。
3. **六线谱 Canvas**：双声部谱面。旋律声部蓝色符干向上，低音声部橙色符干向下；浅色休止表示空余时值，显式休止用声部颜色。单小节超宽时可横向滚动，选择与播放自动定位到当前音符。
4. **检查器（右侧）**：当前选中事件或音符的技巧、目标品位、力度、歌词，以及文档级拍号、速度（BPM）与循环小节。
5. **联动指板（下方，可折叠）**：24 品指板随播放游标、活动事件同步高亮。点击标题旁箭头收起，释放高度给谱面；折叠状态保存在本机偏好，不写入曲谱文档。
6. **演奏提示区**：显示所选声部的前句、当前歌词与后句，以及前一个、当前和下一个和弦；可切换"参考调"查看罗马数字级数。

## 我的曲库弹窗

从**曲谱 → 我的曲库**打开：

- 列表支持搜索、新建、批量导入 `.guitarget` 或曲谱 JSON、重命名、打开编辑、导出与移除。
- 详情面板可以**选择音频文件**绑定原声／伴奏／录音，粘贴 **Apple Music 分享链接**，以及**在 Finder 中显示**数据目录。
- 弹窗底部有数据目录入口，指向 `~/Library/Application Support/Guitarget/MyLibrary/`。

## 全局行为约定

- **互斥播放**：曲谱合成、学习室试听、调音参考音与附加音频在同一进程内最多只有一个在播放；另一个窗口开始播放会暂停旧音频并保留位置。
- **外观**：界面跟随系统深浅色；深色下谱面有独立调校的排版配色。
- **默认值**：A4 = 440 Hz、标准调弦 `[64,59,55,50,45,40]`（第 1 弦到第 6 弦的 MIDI 音高）、4/4 拍、80 BPM。
- **权限最小化**：编辑、保存、普通试听不触碰录音权限；只有点击"开始采集"才请求麦克风或系统音频录制授权。

> **提示**：想快速上手，建议顺序是——先在**指板**点几个音熟悉音名，再到**曲谱 → 我的曲库**打开《小星星》，跟着播放看歌词高亮，然后回到编辑器按《六线谱编辑器与键盘输入全解》录入你自己的第一个小节。
