# Apple Music 链接

曲库条目可以绑定一首 Apple Music 曲目作为参考录音。Guitarget 的处理方式非常克制：**只在本地保存链接文本，播放交给系统原生"音乐"应用**。本文说明操作步骤、工作原理与边界。

## 绑定步骤

1. 在 Apple Music（"音乐"App）中找到目标曲目，选择 **分享 → 复制链接**，得到 `https://music.apple.com/...` 或 `musics://...` 形式的链接。
2. 打开 Guitarget 的**我的曲库**弹窗，选中要绑定的曲目条目。
3. 把链接粘贴到 Apple Music 链接栏并保存。
4. 之后在曲库详情点击**在"音乐"中打开**，系统会唤起原生"音乐"应用定位到该曲目；请在"音乐"中开始播放。

## 工作原理

- 应用把链接作为字符串保存在本机曲库清单（`library.json`）中，不联网、不解析、不缓存任何音频。
- 点击打开时通过系统 URL 处理机制移交：`musics:` 链接已验证解析到 `com.apple.Music` / `Music.app`。
- Guitarget 自身**不会下载受保护的 Apple Music 音频**，也不在应用内播放流媒体内容。

## 边界与注意事项

| 事项 | 说明 |
| --- | --- |
| 播放可用性 | 曲目与完整播放取决于你的地区、Apple 账号及订阅状态 |
| 不自动同步 | 不提供原声与谱面的自动时间对齐；练习谱不预设与某一录音同步 |
| 编配差异 | Apple Music 中同名录音可能在调性、速度、引子和编配上与练习谱不同 |
| 导出 | 普通曲谱导出只包含谱和歌词；Apple Music 绑定属于本机曲库，不随导出打包 |
| 版权 | 请自行确认对所链接内容的使用权利；绑定链接本身只是个人参考 |

## 与附加音频的区别

| 维度 | 附加音频（本地文件） | Apple Music 链接 |
| --- | --- | --- |
| 存储 | 音频字节复制进曲库 UUID 目录 | 只存链接文本 |
| 播放 | 在 Guitarget 编辑窗口内播放，共用进度控制 | 跳转到系统"音乐"应用播放 |
| 演奏模式 | 进入只读演奏模式并智能跟随 | 不进入演奏模式，无跟随 |
| 离线 | 绑定后可离线播放 | 取决于"音乐"应用与订阅 |

> **提示**：想把流媒体曲目当作跟练伴奏，目前唯一的原生路径是：在"音乐"中播放，同时在 Guitarget 打开对应谱面手动对照。若需要智能跟随，请用你拥有使用权的本地音频文件走"附加音频"路径。
