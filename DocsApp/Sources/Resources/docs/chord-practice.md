# 和弦练习模式

和弦练习把"看、听、记住"三种训练方式和三种判定方式组合成可量化的 drills：选择根音集合、大／小和弦与轮数，逐轮训练并分别记录自动判定与自评结果。

## 训练设置

1. **根音集合**：勾选要练的根音（可全选十二个，或只留 C、G、D、A、E 等常用）。
2. **和弦性质**：大和弦、小和弦或混合。
3. **轮数**：本轮 session 的卡片数量。
4. **训练模式**：看图、听示范或限时记忆（下节）。
5. **判定方式**：逐弦单音、整和弦识别或扫弦自评（见判定一节）。

## 三种训练模式

| 模式 | 流程 | 训练目标 |
| --- | --- | --- |
| 看图 | 直接显示按法图示，照着按 | 建立指型与手感的初始映射 |
| 听示范 | 先**隐藏图示**，自动播放分解示范，听完后复现 | 耳朵到手指的连接 |
| 限时记忆 | 显示指法与倒计时（如五秒），倒计时结束后**隐藏图示和目标音名**，仅提示演奏弦序 | 脱离视觉依赖的肌肉记忆 |

任意模式下都可以：**揭示提示**、**再次试听**或**跳过本轮**；结果会保留"是否使用提示"，方便回顾真实掌握度。

## 三种判定方式

### 逐弦单音判定

- 按**低音到高音**逐根演奏目标音。
- 拨下一根前先消掉上一根的余音；每根弦要求**新的起音与稳定单音**（±25 音分、120 ms 稳定）。
- 边界：检查只证明"依次出现了目标音高"，**不能判断真实弦位或同时发声的和弦**。

### 整和弦识别判定

- 扫响整个和弦并保持。
- **提示之后的新一次扫弦**、识别出的根音与和弦性质与目标一致并**连续保持 0.3 秒**即通过。
- 低音不同（如目标 C 弹出 C/E）只作**转位提示**，不判失败；识别为其他和弦时显示所听到的名称并继续等待。
- **不计入**的帧：示范余音、示范期间与采集关闭时的帧；"手动继续"记为手动，不算通过。

### 扫弦自评

- 不进行自动判定，纯靠耳朵。
- 每轮之后仍可用"**清晰、熟练**"、"**还需练习**"或"**跳过本轮**"自评。

两种自动判定都**不评价扫弦质量**（是否整齐、有无闷弦），这是当前算法边界。

## 结果记录

三类结果分别显示、互不混淆：

| 指标 | 来源 |
| --- | --- |
| 自动通过弦数 | 逐弦单音判定 |
| 整和弦识别通过轮数 | 整和弦识别判定 |
| 自评轮数 | 扫弦自评（含"还需练习"） |

验收示例：无采集时看图练习仍可开始一轮（显示 Em 与指法），手动继续一次再自评"还需练习"，结果为自动 0/4、手动 1——**自评不会被误记为自动通过**。

## 状态机与中断处理

练习会话有明确的阶段状态机（7 项 XCTest 覆盖）：看图／听示范／记忆阶段、单音新起音、提示与手动跳过、**音频中断、采集关闭与恢复**都有用例。采集关闭时判定暂停，恢复后继续等待新证据，不把中断期间的静音算作失败。

## 建议练习流程

1. 第一轮：**看图 + 扫弦自评**，把每个和弦的手型摆对。
2. 第二轮：**听示范 + 逐弦单音**，确认每根弦都清晰发声。
3. 第三轮：**限时记忆 + 整和弦识别**，脱离图示直接扫出正确和弦。
4. 每轮结束看三项统计：自动通过弦数低 → 回看图模式；识别通过少但自评好 → 检查扫弦是否让六弦持续响足 0.3 秒。
5. 弱项和弦回到《三和弦与和弦库》查更舒适的按法候选。

> **提示**：整和弦识别判定复用《和弦识别》的 205 模板引擎，识别准确率的验证范围同样适用——离线证据充分，真琴测量未完成。判定不通过时先看"所听到的名称"：它经常告诉你实际扫出了什么（比如漏了根音变成转位）。
