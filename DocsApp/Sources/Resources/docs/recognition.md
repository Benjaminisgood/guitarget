# 和弦识别

和弦识别让 Guitarget"听懂"你扫出的和弦：实时显示和弦名（含 C/E 之类的转位低音）、构成音、分解出的各个音、十二音级能量、整体音准偏差与候选列表。算法为纯手写 Swift（自研 FFT + NNLS + HMM），无第三方库、无 Accelerate 依赖、无训练权重。

## 使用步骤

1. 窗口底部**声音来源**选择麦克风／外接声卡（或系统声音），点击"开始采集"。
2. 进入**和弦识别**栏目，扫响一个和弦并让它**持续约半秒**。
3. 读取结果：和弦名、匹配度、置信度与候选。
4. 点击指板上高亮的位置可试听对应音高。

窗口底部状态栏在**任意栏目**都会同步显示当前识别到的和弦或强力和弦。

## 界面元素

| 元素 | 说明 |
| --- | --- |
| 和弦名与性质 | 低音是根音以外的和弦音时显示转位（如 C/E）；只有根音加五音显示强力和弦（E5）；只有一个音显示单音；宽带噪声或无法匹配显示"无和弦" |
| 匹配度与置信度 | 模板余弦匹配度、HMM 后验置信度、连续保持时长 |
| 音准偏差 | 会话内估计的整体偏离十二平均律的音分值（−50…+50） |
| 构成音 | 目标和弦的音级列表 |
| 分解音 | NNLS 分解出的各个音（含八度），E2–B6 范围 |
| 十二音级能量条 | 上排为高音区色度，下排小块为低音区能量；橙色为当前和弦构成音 |
| 候选列表 | 前三名及其分数 |
| 指板高亮 | 所有与分解音高相同的位置，点击试听 |
| 最近记录 | 持续 0.25 秒以上的和弦及其时长 |

## 覆盖范围

判定词表共 **205 个模板**：

- 15 种和弦性质 × 12 根音 = 180 个（性质列表见《三和弦与和弦库》）；
- 12 个强力和弦、12 个单音、1 个"无和弦"。

## 延迟与判定节奏

- 分析窗口取最接近 **0.34 秒**的 2 的幂（44.1／48 kHz 为 16384 点），每 **1/8 窗口（约 43 ms）**分析一次。
- 结果以**窗口中心时间**为准，比实际弹奏晚约 **0.2–0.5 秒**；判定切换还需要 2–5 帧证据，合成扫弦的新和弦在边界后 0.08–0.36 秒被锁定。
- RMS 低于 0.004 的窗口视为静音：不更新判定，只让旧信念缓慢回到均匀先验。

## 让识别更准的技巧

1. **让六根弦一起响足半秒**——短促扫弦可能只有 1–2 个有效窗口。
2. 先调音：整体失谐超过 ±50 音分会超出补偿范围（算法可自动补偿 −32 音分级别的失谐并已在离线测试验证）。
3. 安静环境，避免鼓、人声等非吉他声源；它们不在词表内但会污染能量条。
4. 扫弦瞬态（拨片触弦的宽带冲击）可能让边界帧出现过渡判定，稳定后 1–4 帧内收敛。

## 明确边界

- **不推断按弦位置**：只显示音高在指板上的所有等价位置。
- **不识别非标准调弦下的开放和弦名**：模型假设标准十二平均律音高。
- 未在真琴与麦克风条件下测量准确率；离线证据见下节，**不要把离线通过率当成真实环境准确率**。
- 极弱的弦（如合成模型中很弱的一弦色彩音）可能被分解噪声清理规则剔除。

## 算法与验证摘要

识别管线八步（细节见《架构与技术实现》）：对数频率谱 → 音准估计 → 噪声底压缩 → NNLS 近似转录（E2–B6 共 56 音）→ 清理 → 音级折叠（高音／低音区色度分开）→ 205 模板余弦匹配加低音奖励 → 带惯性的 HMM 前向滤波（切换概率 0.03、锐度 18）。

| 验证 | 结果 |
| --- | --- |
| 离线合成 180 个首选按法 | 177 个正确命名；B♭6、E♭add9、C♯m6 的色彩音只在合成模型极弱的一弦上出现 |
| 全部大小三和弦（44.1／48 kHz） | 通过 |
| C–G–Am–F–C/E 进行 | 通过，转位低音正确标出 |
| −32 音分整体失谐 | 自动补偿后通过 |
| 宽带噪声 | 判为"无和弦" |
| 实时链路冒烟（process tap 只采集 afplay） | 180 帧、平均匹配 0.95、五段依次为 C、G、Am、F、C，末段全部帧带 E 低音 |
| 每跳处理耗时 | 约 0.7 ms（预算 42.7 ms，M5 实测） |

> **提示**：识别是"整和弦判定"，服务的是和弦练习与状态栏显示；它不做逐音复音转录评分。想在跟练里判定和弦，请使用《和弦练习模式》的整和弦识别判定，规则（0.3 秒保持、转位只提示）在那里定义。
