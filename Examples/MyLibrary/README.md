# 我的曲库 · 入门曲谱

这六份 `.guitarget` 文件与 App 内置的入门曲谱一致，可以在“我的曲库”中导入、改名、编辑和关联自己的本地音频。全部使用标准调弦：从第 1 弦到第 6 弦为 E4、B3、G3、D3、A2、E2。这里列出的旋律音高为实际发声音高。

| 文件 | 内容 | 练习方法 |
| --- | --- | --- |
| `01-Chromatic.guitarget` | 1–2–3–4 半音爬格子，12 小节，60 BPM | 从第 6 弦走到第 1 弦，再以 4–3–2–1 返回。左手食指至小指依次对应 1 至 4 品，右手交替拨弦，每拍一音。 |
| `02-C-Major-Scale.guitarget` | C 大调单八度上下行，4 小节，60 BPM | 实音 C3–C4–C3，注意换弦与均匀节拍，最后一个 C 保持两拍。 |
| `03-Arpeggio.guitarget` | C–Am–Fmaj7–G 分解和弦，两轮共 8 小节，60 BPM | 每小节八个八分音符，右手 p–i–m–a–m–i–m–i。Fmaj7 只拨 4、3、2、1 弦，无需横按。谱面时值用于练习每次拨弦的节奏，实际演奏可在同一和弦内保留余音。 |
| `04-Twinkle-Twinkle.guitarget` | 《小星星》完整常见旋律，12 小节，72 BPM，英语歌词 | 先练旋律，再按事件下方的音节轻唱；短横线表示一个词拆成多个音节。每句末尾的二分音符保持两拍。 |
| `05-Ode-to-Joy.guitarget` | 贝多芬《欢乐颂》主题前 8 小节，72 BPM | 单音旋律，练习重复音与第 4、8 小节的“附点四分＋八分＋二分”节奏；这是主题节选。 |
| `06-Frere-Jacques.guitarget` | 《Frère Jacques／两只老虎》传统旋律，8 小节，72 BPM，法语歌词 | 对照歌词练四分、八分与二分音符；末两小节的 G 在主音 C 下方，用第 6 弦 3 品。这里编写的是单旋律，非多声部轮唱。 |

## 来源与使用

爬格子、音阶和分解和弦由本项目编写；三首经典旋律均采用公版原曲，并由本项目独立编写适合初学者的指法与简化六线谱，没有复制现代出版物的编配。

- 《Twinkle, Twinkle, Little Star》使用传统法国旋律《Ah! vous dirai-je, maman》，英语歌词取自 Jane Taylor 1806 年发表的诗作《The Star》第一节。旋律与原文均为公版。
- 《Ode to Joy》取自 Ludwig van Beethoven 于 1824 年完成的《第九交响曲》欢乐颂主题；本文件为移调到 C 大调的单旋律节选，无歌词。
- 《Frère Jacques》为传统法国儿歌与法语歌词；标题中的“两只老虎”用于识别熟悉的旋律，文件没有收录该中文改词。

文件只包含曲谱和所注明的歌词，没有原声录音。关联本地音频时请选择你已有使用权的文件；商业录音有独立于公版旋律的权利。Apple Music 中同名录音可能在调性、速度、引子和编配上不同，这些练习谱不预设与某一录音同步。
