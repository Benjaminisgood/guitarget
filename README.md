# Guitarget

用反复练习的方式学会吉他。

这是我写来练琴的 macOS 应用。学习室侧栏那句「从一个音，到一首歌」就是范围：先在指板上认识音，再练音阶、和弦和调音，然后对着自己的六线谱反复弹。合成、曲库、跟练和和弦识别都在本机完成，不打开网页，也不下载模型。

这里说的「反复」，是同一次打开里把音和和弦再弹一遍：弹对了再前进，或者按节拍跟着走，和弦练习会把选中的和弦打乱后再来一轮。练习对错记在这一次里，关掉就没了。跨天的复习日程还没有做。

## 现在能做的事

学习室有十个栏目。曲谱是另一扇原生文档窗口。

- **指板**：点击音符试听。音名／音级、根音、15／24 品可以切换。相同 MIDI 音高的位置会一起亮，不推断你实际按在哪根弦。
- **音阶**：12 个根音 × 6 类音阶（大调、自然小调、大／小调五声、大／小调布鲁斯）。可以看全指板，或看明确的 CAGED 五型，上下行试听，或生成一份独立曲谱。音名按调性拼写。
- **CAGED**：选实际根音、大／小和弦和形状，看空弦、消音、指法和琶音。简化按法旁边有说明。
- **三和弦**：选一个大调，看 I–vii°。和弦的根、三、五音画在所选大调指型里，可以试听，也可以生成练习谱。
- **和弦库**：12 个根音和 15 种和弦类型。按品位、跨度、发声弦数、转位、空弦和横按条件算出候选按法，分页看，可以逐音听，也可以扫弦听。
- **调音器**：色度、自动目标弦、锁弦。七种调弦预设，A4 在 400–480 Hz、步进 0.5 Hz，还有参考音、稳定性和最近八秒的偏差。这些预设只给调音器用，不改已经打开的曲谱。
- **和弦识别**：扫一个和弦，实时显示和弦名（含 C/E 这种转位低音）、构成音、分解出的音、十二音级能量、整体音准偏差和候选。覆盖 15 种和弦性质 × 12 个根音，另有强力和弦、单音和「无和弦」。窗口底部状态栏也会显示当前和弦。
- **合奏**：四种原创双声部吉他伴奏。可以转调、调速度、循环、跳到小节、加预备拍。按当前和弦显示推荐音，也能生成单音练习谱。
- **和弦练习**：看图、听完示范再弹、限时记忆。判定可以是逐弦单音、整和弦识别（扫弦后根音和性质对上，并持续 0.3 秒），或只做自评。自动结果和自评分开记。
- **曲谱**：原生的新建、打开和最近文档。「我的曲库」管理自己的谱、歌词和原声。

五个较晚加上的栏目（和弦库、调音器、和弦识别、合奏、和弦练习）的操作细节在 [和弦、调音与合奏指南](docs/learning-expansion.md)。

## 我的曲库、歌词与原声

从学习室的 **曲谱 → 我的曲库** 打开管理弹窗。第一次使用会放进六份自编入门谱：半音爬格子、C 大调音阶、C–Am–Fmaj7–G 分解和弦、《小星星》英语歌词版、《欢乐颂》主题、《Frère Jacques》（两只老虎旋律）法语歌词版。经典旋律和所用历史歌词是公版，编配是这个项目写的，没有附商业录音。`Examples/MyLibrary/` 里有同样的副本，同目录有练习指导。

曲库可以搜索、新建、批量导入 `.guitarget` / 曲谱 JSON、重命名、打开编辑、导出和移除。在曲库里打开的文档按 ⌘S 保存后，修改留在曲库内。外部或未保存的文档，可以用编辑器工具栏的 **存入我的曲库** 存一份当前内容的新副本。移除前要先保存并关掉那个曲库文档窗口。曲库里的名称是管理用的；谱内标题在编辑器里改。

在谱面上选一个音符或休止，在检查器的 **歌词** 栏输入字、词或音节。歌词按事件排在六线谱下面，播放时跟着亮，可以点选、撤销重做、复制粘贴，保存再打开还在。长文字会换行或错行。旧文件没有歌词字段也能打开。

在曲库详情里 **选择音频文件**，绑上自己的原声、伴奏或录音。系统能解码的 WAV、AIFF、MP3、M4A、AAC、CAF、FLAC 都可以。音频会复制进曲库，源文件以后挪走也不影响播放。编辑窗口第一行可以选「曲谱合成」「无伴奏演奏」或这份附加音频，播放、暂停、停止和进度是同一套控制。

选了附加音频就进入只读演奏：不能改谱，也不能点谱面定位。谱面跟的是麦克风或声卡听到的单音。附加音频走系统默认输出，音频时间和你弹到谱上的哪一格是分开的。合成音和附加音频不会同时响。跟随可以选旋律或低音声部，同一个音要重新拨弦。和弦和连续变音技巧先等后面的单音来定位。

可以粘贴 Apple Music 的 **分享 → 复制链接**，保存后点 **在「音乐」中打开**。应用只在本地留下 `https://music.apple.com` 的链接，再交给系统「音乐」。曲目能不能播，取决于地区、账号和订阅。这里不会下载受保护的 Apple Music 音频，也不会把原声和谱面对齐。

数据在 `~/Library/Application Support/Guitarget/MyLibrary/`：`library.json` 是目录，每份谱一个 UUID 文件夹，里面是 `score.guitarget` 和音频副本。弹窗底部可以在 Finder 里显示这个目录；备份时复制整个目录。普通导出只带谱和歌词，音频和 Apple Music 链接属于这台机器上的曲库。QA 实例用另一份 `~/Library/Application Support/Guitarget QA/MyLibrary/`。

「声音来源」在窗口底部。编辑、保存和普通试听不需要录音权限。采集要自己打开。默认是 A4 = 440 Hz、标准调弦、4/4、80 BPM。

## 六线谱怎么输入

先点谱面，选好弦和时间，再输入品位。0–24 品的两位数字在 0.8 秒内合成一个品位。方向键移动，Tab 在旋律／低音之间切换，Return 前进。W、H、Q、E、S、T 是全音符到三十二分音符；`.` 附点，R 休止，L 延音，Delete 删除，空格播放／暂停。复制粘贴、撤销重做用 macOS 那一套。工具栏里有常用时值。检查器里设技巧、目标品位、力度、拍号、速度和循环小节。

两个声部各自计时。同一拍、同一声部的多根弦写成一个和弦。和弦里只有一根弦要延音时，把事件拆成相邻时段，只给那根弦勾「延音至下一音」。还没接上的延音会警告，方便先写下起点。容量不够或同弦重叠时，这一步会被拒绝，另一个声部不动。

拍号目前是 2/4、3/4、4/4、6/8。三连音只做八分音符。文档版本只认 1。

## 跟练

学习页和曲谱工具栏都能打开练习。打开输入后，选「弹对再前进」或「按节拍跟练」。按节拍时默认有预备拍和节拍器，两个声部先静音。听示范的时候暂停评分。默认是音准 ±25 音分、稳定 120 ms、起音 ±150 ms。同一个音再出现，要有新的起音；连上的延音不再打一次分。和弦、死音、击弦、勾弦、滑音、推弦、揉弦会明确跳过。弹对再前进时，跳过的音要手动继续。

「跟拍校准」取多次起音的中位偏移，里面包含人跟拍的误差。声卡本身的延迟要用物理回环才量得准。音高窗口的时间和起音时间是分开留的。麦克风对着扬声器时，串音消不掉，出声练习请戴耳机。

一次练习结束时能看到已评分数量、通过比例、漏音和平均绝对时值偏差。这些数字停在当前窗口。更细的状态机、曲谱 ticks 和哪些东西会写盘，写在 [项目介绍](docs/项目介绍.md)。

## 运行环境

| 项目 | 实际情况 |
| --- | --- |
| 系统 | macOS 15 或更新。`LSMinimumSystemVersion` 是 15.0。这套代码在 macOS 26 上验证过 |
| 语言与 UI | Swift 6 工具链，`Package.swift` 的 tools 版本是 6.0，语言模式是 Swift 5。界面文案是中文。Info.plist 的开发区域是 `zh_CN`，也列了 `en`，仓库里没有单独的英文字符串表 |
| 工程 | Swift Package Manager。没有 XcodeGen，也没有提交 `.xcodeproj` |
| Xcode | 没有锁定版本。装了 Xcode 时，测试脚本会改用 `/Applications/Xcode.app` 的工具链，因为有的 Command Line Tools 不带 XCTest |
| 形态 | 只做 Mac。包标识是 `com.guitarget.mac`，版本号 1.0（1）。没有 iOS 目标，也就没有免费 Apple ID 的描述文件这条路 |
| 依赖 | 应用本体没有第三方包、WebView、Python 或训练模型。音频用 AVAudioEngine 和 CoreAudio process tap |
| 签名 | 打包脚本做本机临时签名 `codesign --sign -`，用来在这台 Mac 上打开。不做公证，也不做对外分发 |

DSP 模块在 Debug 构建里也会打开优化，好赶上实时音频的时限。界面和曲谱模块仍是普通调试构建。

## 构建与启动

在仓库根目录：

```sh
./script/build_and_run.sh
```

脚本会 `swift build`，把可执行文件和 `script/Info.plist`、`script/Guitarget.icns` 装进 `dist/Guitarget.app`，做临时签名，再用 `open` 启动。Codex 的 **Run** 按钮走的是同一条命令。

启动前会请已经开着的 Guitarget 正常退出。还有未保存文档时，系统会问你。取消关闭的话脚本不会强杀进程，并请你处理保存对话框后再试。图标文件缺失会中止打包。签名之后会改包目录时间并重新登记，让 Finder 和程序坞刷新图标。

可选参数：`--build-only`、`--verify`、`--debug`、`--logs`、`--telemetry`。

用 Xcode 打开时，打开 `Package.swift` 即可，SwiftPM 会自己生成临时工程。仓库不提交那份工程。

测试：

```sh
./script/test.sh
```

这就是检测到 Xcode 后设置 `DEVELOPER_DIR`，再执行 `swift test`。后面可以跟 `swift test` 自己的参数。

第一次打开麦克风或系统声音采集时，系统会按 Info.plist 里的说明弹权限。编辑、保存和合成试听不必授权。

开发自检、QA 包和模块分工写在 [项目介绍](docs/项目介绍.md)。

## 代码放在哪

| 路径 | 做什么 |
| --- | --- |
| `Sources/GuitarCore` | 乐理、唯一的 `GuitarScore`、ticks、校验、延音调度、跟练状态机、和弦练习、曲库模型 |
| `Sources/GuitarAudio` | 六弦合成、播放时钟、采集、process tap、YIN、自研 FFT / NNLS 和弦识别 |
| `Sources/Guitarget` | SwiftUI 窗口、原生文档、Canvas 六线谱、曲库界面 |
| `Tests` | 乐理、文档、调度、识别和练习的回归 |
| `Examples` | 可直接打开的谱，以及生成这些谱的 Swift 脚本 |
| `convertor` | 独立的离线 Guitar Pro 转换器，不进应用进程 |
| `script` | 打包、测试、图标、QA 包 |
| `docs` | 格式、编辑器、音频、验收和这份介绍 |

`.guitarget` 是版本化 JSON，四分音符固定 **960 ticks**，谱面不存浮点秒。生成谱可以按 [格式说明](docs/score-format.md) 写。

## 许可和来源

仓库根目录没有 `LICENSE`，GitHub 仓库也还没选开源许可证。要再分发的话，得先由作者定。

应用运行时不带第三方库。`convertor/` 在自己的 Python 环境里使用 [PyGuitarPro](https://github.com/Perlence/PyGuitarPro)（LGPL-3.0），那份依赖不打进 App。旧 GP 的回退运行时见 [convertor/README-legacy.md](convertor/README-legacy.md)。

入门谱里的《小星星》《欢乐颂》《Frère Jacques》用的是公版旋律和所注明的历史歌词，指法和六线谱是这个项目写的。出处和练习方法在 [Examples/MyLibrary/README.md](Examples/MyLibrary/README.md)。
