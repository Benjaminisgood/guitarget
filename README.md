# Guitarget

纯 Swift 原生 macOS 吉他学习、双声部六线谱与歌词编辑、本地曲库、钢弦吉他合成和单音跟练。SwiftUI / AppKit、AVAudioEngine、CoreAudio process tap；无 WebView、Python、外部运行时或第三方包。曲库无需联网，Apple Music 链接交给系统“音乐”应用打开。

## 构建与启动

需要 macOS 15 或更新系统、Swift 6 工具链；本项目在 macOS 26 验证。

```sh
./script/build_and_run.sh
```

生成并启动 `dist/Guitarget.app`。Codex 的 **Run** 按钮调用同一脚本。脚本先正常关闭现有应用；未保存文档由系统处理，取消关闭时不会强制杀进程。可选 `--build-only`、`--verify`、`--debug`、`--logs`、`--telemetry`。本地临时签名用于开发，不包含对外分发或公证。

```sh
./script/test.sh
```

测试脚本在存在 Xcode 时使用它的工具链，因为部分 Command Line Tools 安装不包含 XCTest。DSP 模块的 Debug 构建也启用优化，以满足实时音频预算；UI 和曲谱模块仍保留调试构建。

## 开始使用

- **指板**：点击音符试听；音名／音级、根音和 15／24 品可切换。识别高亮相同 MIDI 音高的所有位置，不推断实际弦位。
- **音阶**：12 根音 × 6 类音阶，选择全指板或明确的 CAGED 五型，上下行试听或生成独立曲谱文档。音名按调性拼写。
- **CAGED**：选择实际根音、大／小和弦及形状，查看空弦、消音、指法和琶音。简化按法附有说明。
- **三和弦**：选择大调及 I–vii°，在所选大调指型内显示和弦根、三、五音，试听并生成练习谱。
- **和弦库**：12 根音与 15 种和弦类型组合，按品位、跨度、发声弦数、转位、空弦与横按条件计算候选按法，分页查看、逐音或扫弦试听。
- **调音器**：色度、自动目标弦和锁弦；七种调弦预设、400–480 Hz A4 基准、参考音、稳定性与近期偏差历史。预设只用于调音器，不更改曲谱调弦。
- **合奏**：四种原创双声部吉他伴奏，支持转调、速度、循环、小节定位和预备拍；按当前和弦显示推荐音，并可生成单音练习谱。
- **和弦练习**：看图、听示范后复现、限时记忆。逐弦自动检查单音，完整扫弦由用户自评；两种结果分别记录。
- **曲谱**：原生新建、打开和最近文档；“我的曲库”弹窗管理自己的曲谱、歌词和原声。

## 我的曲库、歌词与原声

从学习室的 **曲谱 → 我的曲库** 打开管理弹窗。首次使用自动加入六份自编入门谱：半音爬格子、C 大调音阶、C–Am–Fmaj7–G 分解和弦、《小星星》英语歌词版、《欢乐颂》主题、《Frère Jacques》（两只老虎旋律）法语歌词版。经典旋律及所用历史歌词为公版，编配由本项目编写，未附商业录音。可导入副本在 `Examples/MyLibrary/`，同目录附练习指导。

曲库支持搜索、新建、批量导入 `.guitarget` / 曲谱 JSON、重命名、打开编辑、导出和移除。在曲库打开的文档按 ⌘S 保存后，修改留在曲库内。外部或未保存文档可用编辑器工具栏的 **存入我的曲库** 保存当前内容的新副本。移除前需要先保存并关闭该曲库文档窗口。曲库中的名称是管理用名称；谱内标题由编辑器修改。

在谱面选择一个音符或休止事件，在检查器的 **歌词** 栏输入对应的字、词或音节。歌词按事件对齐在六线谱下方，随谱面播放高亮，支持点击选择、撤销重做、复制粘贴及保存重开。长文字会换行或错行排列。旧版没有歌词字段的曲谱仍可打开。

在曲库详情中 **选择音频文件** 绑定自己的原声、伴奏或录音，支持系统可解码的 MP3、M4A、WAV、AIFF 等格式。音频复制到曲库；源文件移动后不影响播放。曲库弹窗和该谱的编辑窗口均可播放、暂停、停止、拖动进度。原声使用系统默认输出，独立于谱面变速、循环、跟练和合成器计时。

可粘贴 Apple Music 的 **分享 → 复制链接**，保存后点击 **在“音乐”中打开**。应用只在本地保存链接，再交给原生“音乐”应用；请在那里开始播放，曲目与完整播放取决于地区、账号及订阅。不会下载受保护的 Apple Music 音频，也不提供原声与谱面自动同步。

数据保存在 `~/Library/Application Support/Guitarget/MyLibrary/`：`library.json` 为目录，每份谱使用独立 UUID 子目录保存 `score.guitarget` 和音频副本。弹窗底部可在 Finder 显示该目录；备份应复制整个目录。普通曲谱导出只包含谱和歌词，音频与 Apple Music 绑定属于本机曲库。QA 实例使用独立的 `Guitarget QA/MyLibrary/`。

“声音来源”在窗口底部，输入和输出独立选择。采集需要用户启用；编辑、保存和普通试听不要求录音权限。默认 A4 = 440 Hz、标准调弦、4/4、80 BPM。界面跟随系统外观。

## 六线谱键盘

先点击谱面选择弦和时间，再输入品位。0–24 品的两位输入在 0.8 秒内组合。方向键移动，Tab 切换旋律／低音，Return 前进。W、H、Q、E、S、T 对应全音符至三十二分音符；`.` 附点、R 休止、L 延音、Delete 删除、空格播放／暂停。复制粘贴和撤销重做使用标准 macOS 快捷键。工具栏提供全部常用时值，检查器设置技巧、目标品位、力度、拍号、速度及循环小节。

两个声部独立计时；同拍多弦组成和弦。对和弦内一根弦延音时，把事件拆成相邻时段，仅给该弦勾选“延音至下一音”。未连接的延音显示警告，便于先录起点再录续音。容量或同弦重叠错误会拒绝当前操作，不移动另一声部。

## 跟练

学习页和曲谱工具栏都能打开练习。启用输入后，选择“弹对再前进”或“按节拍跟练”；后者默认预备拍和节拍器，两个声部静音。示范期间暂停评分。默认音准 ±25 音分、稳定 120 ms、起音 ±150 ms。重复同音需要新起音，连接延音不重新评分。和弦、死音、连续变音技巧明确跳过；等待模式可手动继续。

“跟拍校准”使用多次起音的中位偏移，包含人的跟拍误差；准确声卡延迟需物理回环测量。音高窗口时间和独立起音时间分别保留。麦克风下的扬声器串音无法保证消除，带声音练习请佩戴耳机。

## 工程与开放文档

| 路径 | 职责 |
| --- | --- |
| `Sources/GuitarCore` | 乐理、唯一 GuitarScore 模型、ticks、校验、延音调度、跟练状态机 |
| `Sources/GuitarAudio` | 六弦 DSP、音频时钟、采集设备、process tap、YIN、PitchFrame |
| `Sources/Guitarget` | SwiftUI 场景、原生文档、Canvas 六线谱、小型键盘桥接 |
| `Tests` | 乐理、文档、调度、识别与练习回归 |
| `Examples` | 直接打开的指弹、F 大调及技巧曲谱，以及 Swift 生成脚本 |

`.guitarget` 是版本化 JSON，四分音符恒为 **960 ticks**；不以浮点秒保存谱面。AI 可按 [格式说明](docs/score-format.md) 直接生成。另见 [乐理与判定约定](docs/theory-and-practice.md)、[编辑器说明](docs/editor.md)、[音频实现](docs/audio.md) 和 [验收记录](docs/acceptance.md)。

应用只实现本地六弦吉他与单音评分；无多乐器轨、Guitar Pro 导入、自动转谱或复音和弦评分。

四个新增学习栏目详见 [和弦、调音与合奏指南](docs/learning-expansion.md)。

## 开发诊断

关闭现有应用后，可运行：

```sh
./script/build_and_run.sh --build-only
open dist/Guitarget.app --args --self-check "$PWD/artifacts/app-self-check.json"
```

自检调用原生编辑状态和 UndoManager，并输出六弦数值诊断、`steel-string-demo.wav`、`reference-a4.wav`。它不会启动采集或把算法结果描述为真琴准确率。`script/stage_qa.sh` 可生成独立 bundle ID 的验收实例，避免操作主应用中的文档；该实例仅用于开发。
